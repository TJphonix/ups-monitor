# ⚡ UPS Monitor

UPS Monitor は、無停電電源装置（UPS）の監視および停電やバッテリー低下時における安全処理を自動化するソフトウェアです。

家庭および小規模オフィス環境向けに設計されており、Terramaster NAS（TOS）や他ブランドの UPS、および同一ローカルネットワーク上の複数の PC を集中管理できます。

---

## 🎯 目的

緊急時における監視と自動シャットダウン処理を通じて、システムの継続稼働と機器の安全性を確保します。

---

## ✨ 主な機能

- 📊 UPS 状態のリアルタイム監視  
- ⚡ 停電およびバッテリー状態の検知  
- 🔔 通知およびアラート機能  
- 💻 ネットワーク上の PC および NAS の自動シャットダウン  
- 🖥️ 軽量なデスクトップ GUI  
- 📌 システムトレイ常駐  

---

## 📦 インストール

1. Releases セクションから最新バージョンをダウンロード  
2. インストーラー（`.exe`）を実行  
3. セットアップウィザードに従う  
4. UPS Monitor を起動  

> Python や追加の依存関係は不要です

---

## ⚙️ 設定

設定は GUI から行います。

主な設定項目：

- UPS / NUT サーバーのアドレス  
- ネットワーク上の監視対象デバイス  
- バッテリー閾値およびタイムアウト  
- 自動シャットダウン動作  

設定は JSON 形式でローカルに保存されます。
