# ⚡ UPS Monitor

UPS Monitor is a software solution for monitoring Uninterruptible Power Supplies (UPS) and automatically handling safety actions in case of power outages or low battery conditions.

It is designed for home and small office environments and allows centralized control of a UPS connected to a Terramaster NAS (TOS) (or other brands) and multiple PCs on the same local network.

---

## 🎯 Goal

Ensure operational continuity and device safety by automating monitoring and shutdown actions during emergencies.

---

## ✨ Features

- 📊 Real-time UPS status monitoring  
- ⚡ Power outage and battery status detection  
- 🔔 Notifications and alerts  
- 💻 Automatic shutdown of PCs and NAS over the network  
- 🖥️ Lightweight desktop graphical interface  
- 📌 System tray integration  

---

## 📦 Installation

1. Download the latest version from the **Releases** section  
2. Run the installer (`.exe`)  
3. Follow the setup wizard  
4. Launch UPS Monitor  

> No Python or additional dependencies required

---

## ⚙️ Configuration

Configuration is handled through the graphical interface.

Main parameters:

- UPS / NUT server address  
- Devices to monitor on the network  
- Battery thresholds and timeout  
- Automatic shutdown actions  

Settings are saved locally in JSON format.
