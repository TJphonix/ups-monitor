# ⚡ UPS Monitor

**UPS Monitor** 是一款用于监控不间断电源（UPS）并在断电或电池电量不足时自动执行安全操作的软件。

该软件面向家庭和小型办公室环境，可集中管理连接到 Terramaster NAS（TOS）或其他设备的 UPS，并支持局域网内多台电脑。

---

## 🎯 目标

通过自动监控和在紧急情况下执行安全关机操作，保障设备运行的连续性和数据安全。

---

## ✨ 功能

- 📊 实时监控 UPS 状态  
- ⚡ 检测断电与电池电量  
- 🔔 通知与警报  
- 💻 自动关闭局域网内的电脑和 NAS  
- 🖥️ 轻量级桌面图形界面  
- 📌 系统托盘常驻图标  

---

## 📦 安装

1. 在 **Releases** 页面下载最新版本  
2. 运行安装程序（`.exe`）  
3. 按照安装向导操作  
4. 启动 UPS Monitor  

> 无需安装 Python 或其他依赖

---

## ⚙️ 配置

通过图形界面进行配置。

主要参数：

- UPS / NUT 服务器地址  
- 网络中需要监控的设备  
- 电池阈值与延迟时间  
- 自动关机操作  

配置将以 JSON 格式保存在本地。
