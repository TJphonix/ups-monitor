# ⚡ UPS Monitor

UPS Monitor는 무정전 전원 장치(UPS)를 모니터링하고 정전 또는 배터리 부족 상황에서 안전 조치를 자동으로 수행하는 소프트웨어입니다.

가정 및 소규모 사무실 환경을 위해 설계되었으며, Terramaster NAS(TOS) (또는 다른 브랜드)와 동일한 로컬 네트워크에 연결된 여러 PC를 중앙에서 관리할 수 있습니다.

---

## 🎯 목표

비상 상황에서 모니터링과 자동 종료 기능을 통해 시스템의 안정성과 장치 보호를 보장합니다.

---

## ✨ 주요 기능

- 📊 UPS 상태 실시간 모니터링  
- ⚡ 정전 및 배터리 상태 감지  
- 🔔 알림 및 경고  
- 💻 네트워크 내 PC 및 NAS 자동 종료  
- 🖥️ 가벼운 데스크톱 GUI  
- 📌 시스템 트레이 상주  

---

## 📦 설치

1. Releases 섹션에서 최신 버전 다운로드  
2. 설치 파일(`.exe`) 실행  
3. 설치 마법사 안내에 따라 진행  
4. UPS Monitor 실행  

> Python 또는 추가 종속성 설치가 필요하지 않습니다

---

## ⚙️ 설정

설정은 그래픽 인터페이스를 통해 수행됩니다.

주요 설정 항목:

- UPS / NUT 서버 주소  
- 네트워크에서 모니터링할 장치  
- 배터리 임계값 및 타임아웃  
- 자동 종료 동작  

설정은 JSON 형식으로 로컬에 저장됩니다.
