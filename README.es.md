# ⚡ UPS Monitor

UPS Monitor es un software para la monitorización de sistemas de alimentación ininterrumpida (UPS) y la gestión automática de acciones de seguridad en caso de cortes de energía o batería baja.

Está diseñado para entornos domésticos y pequeñas oficinas, y permite el control centralizado de un UPS conectado a un NAS Terramaster (TOS) (u otras marcas) y a varios PCs en la misma red local.

---

## 🎯 Objetivo

Garantizar la continuidad operativa y la seguridad de los dispositivos conectados al UPS, automatizando la monitorización y las acciones de apagado en caso de emergencia.

---

## ✨ Funcionalidades

- 📊 Monitorización en tiempo real del estado del UPS  
- ⚡ Detección de cortes de energía y estado de la batería  
- 🔔 Notificaciones y alertas  
- 💻 Apagado automático de PCs y NAS en red  
- 🖥️ Interfaz gráfica de escritorio ligera  
- 📌 Icono residente en la bandeja del sistema  

---

## 📦 Instalación

1. Descarga la última versión desde la sección **Releases**  
2. Ejecuta el instalador (`.exe`)  
3. Sigue el asistente de instalación  
4. Inicia UPS Monitor  

> No se requiere instalar Python ni dependencias adicionales

---

## ⚙️ Configuración

La configuración se realiza mediante la interfaz gráfica.

Parámetros principales:

- Dirección del UPS / servidor NUT  
- Dispositivos a monitorizar en la red  
- Umbrales de batería y tiempos de espera  
- Acciones de apagado automático  

La configuración se guarda localmente en formato JSON.
